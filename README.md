# 住まい探しハザードマップ（Hazard Map Housing Navigator）

Googleマップと国土交通省の公式ハザードマップ（オープンデータ）を1画面に重ね合わせて表示し、**住居探し（賃貸・購入・土地選び）における災害リスクの確認・候補地比較を驚くほど簡単にするWebツール**です。

---

## 🌟 主な特徴 & 実装機能

### 1. Googleマップ × ハザードマップのリアルタイム重ね合わせ
* **Googleマップ（道路・施設地図）** と **Google航空写真（ハイブリッド）** の上に、国土交通省のハザードマップを透過オーバーレイ。
* **透過度スライダー（0%〜100%）**: 濃さを自由に調整でき、ハザードの色の下にある道路、スーパー、駅、学校がそのまま透けて見えます。
* **ハザード一時OFFボタン**: ワンクリックでハザード色をパッと消して、Googleマップを素早く確認できます。

### 2. 地図上クリックで「ピンポイント即時リスク診断」
気になる物件や土地を地図上でクリックするだけで、以下の情報を即座に判定します：
* 💧 **想定浸水深**: 「0.5m未満」「0.5〜3.0m（1階床上）」「3.0〜5.0m（2階床下）」「5.0m以上（2階水没）」などを自動診断
* ⛰️ **土砂災害警戒区域**: イエローゾーン（警戒区域）やレッドゾーン（特別警戒区域）の該当有無を自動判定
* 🏚️ **家屋倒壊等氾濫想定区域**: 氾濫流警戒区域の該当有無
* 🏔️ **海抜・標高**: 国土地理院APIと連携し、その地点の標高（海抜何メートルか）を表示

### 3. 周辺環境の直行チェック（Google連携）
ポップアップからワンクリックで：
* 🚶 **Googleストリートビュー**: 現地の道路幅、坂道の傾斜、側溝や擁壁、街並みを実写で確認
* 🗺️ **Googleマップ本家**: 最寄り駅までの徒歩ルート、スーパーやドラッグストア、病院などの検索へ直行

### 4. 検討中物件リスト & 比較（自動保存）
* 気に入った候補地を「検討中リスト」にピン留め保存可能（物件名、家賃/価格、メモ）。
* ブラウザのローカルストレージに保存されるため、ページを閉じても消えません。
* リストをクリックするとその物件へスムーズにズーム移動し、リスクを再確認できます。
* 家族や不動産会社との共有用に「JSONエクスポート」も可能。

---

## 🚀 使い方

1. `index.html` をお使いのWebブラウザ（Google Chrome, Edge, Safari等）でダブルクリックして開きます。
   （サーバーの起動や特別な環境設定、APIキーの登録は一切不要です）
2. 画面左上の検索バーで、検討したい地域や駅名（例: `福山駅`、`福山市駅家町` など）を検索して移動します。
3. 地図上をクリックすると、その地点のハザード診断と海抜が表示されます。
4. 右上のパネルで「浸水深」「土砂災害」などのレイヤー切り替えや透明度の調整ができます。
5. 「この場所を検討中リストに保存」を押すと、左サイドバーに候補地として蓄積・比較できます。

---

## 📌 出典・利用データ
* ベース地図: Google Maps / 国土地理院タイル / OpenStreetMap
* 災害データ: 国土交通省 ハザードマップポータルサイト（オープンデータ配信）
  * 洪水浸水想定区域（想定最大規模 L2）
  * 土砂災害警戒区域（急傾斜地の崩壊、土石流、地すべり）
  * 家屋倒壊等氾濫想定区域
  * 津波浸水想定区域
* 標高データ・住所検索: 国土地理院 標高API・住所検索API
